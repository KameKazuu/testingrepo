# KameKazuu Extensions

Paperback extensions for websites with unique, non-generic themes.

## Available Extensions

- [AllManga](https://allmanga.to)
- [EHentai](https://e-hentai.org)
- [ExHentai](https://exhentai.org)
- [HiveToons](https://hivetoons.org)
- [Kagane](https://kagane.to)
- [MangaBaka](https://mangabaka.org)
- [Mangago](https://mangago.me)
- [oManga](https://omanga.to)
- [Scans.GG](https://scans.gg)

## Installation

To add these extensions to Paperback, visit the [installation page][repository-installation-page] and tap "Add Repository to Paperback".

## Support

Need help? Open an issue on this repository.

## Contributing

Pull requests are welcome. Run `npm run conformance` and `npm test` before opening one, and bump the `version` field in `pbconfig.ts` for every extension you modify.
